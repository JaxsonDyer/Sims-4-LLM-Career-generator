INSTALL
----------------------------------------------------------------------
1. Copy the .package AND the .ts4script into your Mods folder:
     Windows  Documents\Electronic Arts\The Sims 4\Mods
     macOS    ~/Documents/Electronic Arts/The Sims 4/Mods
   They can sit in a subfolder, but no deeper than one level down.

2. In game: Game Options > Other > enable BOTH
     'Enable Custom Content and Mods'
     'Script Mods Allowed'
   Then restart the game fully. Script mods only load at startup.

3. Delete localthumbcache.package from the The Sims 4 folder. Stale
   cache is the single most common reason a new mod does not appear.

----------------------------------------------------------------------
VERIFYING IT WORKED
----------------------------------------------------------------------
Open the console with Ctrl+Shift+C and run:
     forge.machine_learning_engineer

  Command responds     -> script loaded. If the career is still
                          missing, the .package tuning did not
                          resolve; see TROUBLESHOOTING below.
  Unknown command      -> the .ts4script is not loading. Check that
                          script mods are enabled and the file is
                          not nested too deep.

Then have an adult sim use a phone or computer > Find a Job.
The career appears as 'Machine Learning Engineer'.

TROUBLESHOOTING
----------------------------------------------------------------------
The tuning and SimData follow EA's own careers as of game version
1.127.41.1030, and only reference base-game content. A
later patch can still rename fields. If the career misbehaves,
check the game's exception log, which names the tuning file and
field at fault:
  Documents/Electronic Arts/The Sims 4/lastException*.txt
